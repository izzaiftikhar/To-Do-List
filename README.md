# To-Do List CLI

A simple command-line To-Do List application built with Python. This project allows users to add, view, and delete tasks through an interactive menu.

## Features

- Add new tasks
- View all added tasks
- Delete tasks by task number
- Exit the application through the menu
- Interactive command-line interface

## Concepts Practiced

- Lists
- Functions
- `input()` and user interaction
- `if`, `elif`, and `else`
- `while` loops
- `break`
- `for` loops
- `enumerate()`
- List methods such as `append()` and `pop()`
- Basic program flow and menu-driven programs

## How It Works

The application stores tasks inside a Python list.

Users can choose from four options:

1. Add a task
2. View tasks
3. Delete a task
4. Exit

Tasks are displayed with numbers using `enumerate()`, and the selected task is deleted using `pop()`.
